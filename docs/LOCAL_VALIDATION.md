## Практическая проверка Андреем

1. Закрыть ранее запущенный VirusTotal. Открыть локальную сборку из `Artifacts`
   и проверить русский интерфейс, настройки ключа и квоты на главном экране.
2. Выбрать `PracticeFiles/hello.txt`, затем `Example.app`; проверить результат,
   переход назад, повторный выбор и отмену. Загрузку неизвестного файла
   подтвердить кнопкой в приложении. Файлы в наборе безвредные.
3. Добавить несколько файлов в пакет; проверить «Очистить всё», повторное
   добавление и запуск. До окончания подготовки запуск должен быть недоступен.
4. Выбрать пустую `PracticeFiles/Monitor`, включить автопроверку с согласием,
   затем скопировать туда `sample.zip`. Проверить результат и уведомление;
   выключение мониторинга должно остановить очередь.
5. Проверить фоновый режим: закрыть окно, открыть через менюбар, перезапустить;
   затем проверить Mini Mode и доступ к выбранной папке после перезапуска.

## Повторная сборка

Обычная сборка выполняется `zsh Scripts/create-dmg.sh`; для метаданных Finder
нужны зависимости из `Scripts/requirements-packaging.txt`. Используется прямая
запись `.DS_Store`, без AppleScript и зависимости от момента сохранения Finder.
Исходная картинка не меняется. Локальное подписание сохраняет entitlements Xcode,
добавляет разрешение загрузки встроенного Sparkle для ad-hoc подписи и удаляет
`get-task-allow` у Release. API-ключи и пользовательские данные в артефакты не включены.

Для локального shallow-кэша использовались параметры `-packageCachePath`,
`-clonedSourcePackagesDirPath`, `-onlyUsePackageVersionsFromResolvedFile`,
`-skipPackageUpdates`. `VT_SKIP_BUILD=1` допустим только для повторной упаковки
уже собранного приложения без изменений исходников.
