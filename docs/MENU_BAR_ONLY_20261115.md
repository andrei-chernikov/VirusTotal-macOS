# Режим «Только строка меню»

2026-11-15T10:15:17+0300 [codex]

Реализация запроса issue #34, только локально. Вместо дублирования двух похожих
переключателей прежний Background Monitoring представлен как Menu Bar Only.
Настройка выключена по умолчанию. Ключ хранения `backgroundMonitoringMode`
сохранён для совместимости; Swift-имя теперь `menuBarOnly`. Параметр
`autoScanDownloadsEnabled` остаётся независимым и не включается этим режимом.

## Поведение

- Левый клик по значку сразу открывает существующее окно проверки.
- Правый клик или Control-клик открывает меню: главное окно, настройки, выход.
- Dock скрыт и при открытом главном окне, и при открытых настройках.
- Закрытие главного окна скрывает его, приложение и значок продолжают работать.
- Выключение режима возвращает Dock и убирает значок из строки меню сразу.
- Начальная настройка и явный перезапуск из настроек не скрываются при запуске.
- Mini Mode продолжает работать; выбран обычный Window, а не новый popover,
  поскольку issue прямо допускает оба варианта.

## Проверки

Полный прогон Xcode: **41 тест / 10 suites, PASS**, включая пять новых проверок
AppKit: Dock при открытии окна, закрытие без выхода, отключение режима,
реальный target/action левого клика и доступность первоначальной настройки.
До реализации тесты не компилировались из-за отсутствовавшего интерфейса.

В отдельной UI-копии с bundle ID `org.eu.moyuapp.VirusTotal.MenuBarSmoke`
проверено включение/выключение настройки. Свойство реального процесса
`activationPolicy` изменялось accessory → regular; автосканирование папки
оставалось выключенным. У тестовой копии отдельный контейнер и нет API-ключа.
Раскладка подписи проверена визуально: длинный текст переносится целиком.

Ограничение UI-автоматизации: инструмент не предоставил доступ к значку
в системной строке меню; физический левый/правый клик и холодный старт
вручную ещё не подтверждены. Обработчик левого клика проверен через AppKit
target/action; политика старта и закрытия — интеграционными тестами.

## Сборка и ручная проверка

Универсальная Release-сборка arm64 + x86_64, ad-hoc подпись проверена.
DMG сохраняет исходную картинку. Установленное приложение и данные пользователя
при подготовке обновления не заменялись и не сбрасывались.

1. Установить новый DMG с заменой приложения и открыть Settings → Advanced.
2. Включить Menu Bar Only; проверить левый и правый клик по значку.
3. Закрыть главное окно, затем открыть его значком; Dock не должен появляться.
4. Открыть настройки правым кликом, выключить режим и проверить возврат Dock.
5. Проверить запуск после Quit с включённым режимом и, при желании, Mini Mode.

Изменения не отправлять на GitHub до практической проверки Андреем.
